## 🚀 วิธีการใช้งาน

### 1. เริ่มต้นจาก Step 0.1
```bash
# อ่านไฟล์ step-0.1-setup-model.md
# ทำตามขั้นตอนในไฟล์
# เมื่อทำเสร็จแล้วให้ทดสอบด้วยคำสั่งที่กำหนด
```

### 2. การตรวจสอบความถูกต้อง
แต่ละ step จะมี:
- ✅ **Goal** - เป้าหมายของ step นั้น
- 📝 **Tasks** - สิ่งที่ต้องทำ
- 🔍 **Check** - วิธีตรวจสอบว่าทำถูกต้อง
- 🎯 **Expected Result** - ผลลัพธ์ที่ควรได้
- 🚀 **Next Step** - ลิงก์ไปยัง step ถัดไป

### 3. ระบบ Checkpoint
- แต่ละ step จะมี checkpoint เพื่อตรวจสอบ
- ต้องผ่าน checkpoint ก่อนจึงจะไป step ถัดไป
- มี code snippets สำหรับทดสอบ
